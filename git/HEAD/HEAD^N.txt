
§ HEAD^

- pointer to parent of current HEAD

- multiple parents
	° may occur due to merge
	° first parent chosen, by default
		> cf. reflog
	° cf. HEAD^N notation for referencing parents

- HEAD^N
	NOTE: pointer index relative to current position in branch history not including parent commit history
	° refer to Nth parent or commit WITHIN branch
	° NOT INCLUDED are commits INHERITED from PARENTS!
	° example
		HEAD^  - first parent
		HEAD^2 - second parent
		HEAD^3 - third parent
