
§ rebase

- git-rebase (1)
	° reapply commits on top of another base tip


- reapplying commits
	° integrates commits from one branch into another
	° reapplies commits from source branch into a target branch
	° places source commits onto tip of target commit
	° comparison to merge
		> cleener and more linear than merges 
		> merge differs in that a NEW commit must be created to perform it

- example
	git checkout <target-branch>
	git rebase <source-branch>


- -i 
	° interactive mode
	° temp rebase file opened for editing
	° editing in file
		> reword - rework message of commit
		> edit   - edit commit
		> pick   - keep commit as is
	° general messages:
		> allows commented messages
		> check file afterwards for messages?

- --continue
	° continue with rebase after file modified and saved
	° performs rebase

- --skip
	° if conflicts occur, eg. commits in history
	° overrides and performs rebase
	° --continue not necessary if used
