
§ .gitignore

- gitignore (5)
	° hidden file in git repository
	° specifies intentionally untracked files to ignore
	° eg. .csv 

- ignoring entire directories
	° ignore all files in directory
		> /path/to/directory/**
		> **
			~ needed to ignore all files and directories INCLUDING child  directories
	° ignorea all files AND directories in directory
		> /path/to/directory/*
		> *
			~ needed to ignore all files in directory
